# SiOfi — Landing Page / One Page
## Copy estruturada para implementação no Claude Code

> Documento de referência para desenvolvimento da nova landing page comercial do SiOfi.
>
> Objetivo principal: geração de leads qualificados para demonstração comercial.
>
> Estratégia: conduzir o visitante por **dor → identificação → solução → benefícios → prova → confiança → demonstração**.

---

# 1. Objetivo da página

Criar uma **one page comercial de alta conversão** para o SiOfi, voltada principalmente para:

- donos de oficinas mecânicas em crescimento;
- auto centers / centros automotivos;
- empresas que já utilizam outro sistema e consideram trocar;
- administrativas, gerentes e responsáveis pelo financeiro/recepção que influenciam a decisão.

A página não deve parecer um catálogo de funcionalidades.

A comunicação deve mostrar primeiro os problemas do negócio e, depois, apresentar o SiOfi como ferramenta para organizar e controlar a operação.

CTA principal da página:

**Agendar uma demonstração**

CTA alternativo:

**Conhecer o SiOfi**

# 3. Persona principal da página

## Dono em crescimento

Perfil:

- oficina ou centro automotivo já em operação;
- normalmente possui equipe;
- começa a perder controle conforme o movimento cresce;
- precisa acompanhar financeiro, OS, estoque e equipe;
- não quer passar o dia inteiro alimentando sistema;
- quer saber se o negócio realmente está dando resultado.

Dor central:

**“A oficina trabalha, fatura e se movimenta, mas eu não tenho clareza de quanto realmente sobra.”**

Desejo central:

**Ter controle da oficina sem depender apenas da memória, papel, planilhas ou da presença constante do dono.**

# 26. DIREÇÃO VISUAL

A percepção visual deve ser:

**moderna + confiável + simples + prática**

Evitar:

- estética de ERP antigo;
- excesso de azul corporativo sem contraste;
- fotos genéricas de mecânicos sorrindo;
- excesso de ícones;
- cards demais;
- grandes blocos de texto;
- visual poluído.

Priorizar:

- fundo claro;
- bastante espaço em branco;
- screenshots reais;
- tipografia forte;
- hierarquia clara;
- poucas cores;
- fotos reais de oficinas/clientes;
- elementos automotivos apenas como apoio.

A interface do SiOfi deve ser apresentada como prova do produto, não como decoração.

- taxa de conversão visitante → lead;
- CPL;

- comparecimento;

- CAC;

**gerar demonstrações com empresas que tenham fit real com o SiOfi, e não apenas aumentar o volume bruto de formulários.**
